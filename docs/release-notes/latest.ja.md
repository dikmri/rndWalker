# rndWalker v0.2.1

v0.2.0 のマルチビューに関する不具合修正リリースです。

## 修正内容

### マルチビューの再生速度を修正

- v0.2.0 でタイルの動画が高速再生されてしまう問題を修正しました。省力デコードがフレームを間引いていたことが原因です(画質を軽くするループフィルタ省略は引き続き有効です)。

### タイルのトリミングを廃止し、敷き詰めレイアウトに変更

- 動画の上下左右をカットして正方形セルに敷き詰める方式をやめました。
- 各動画はカットせず全体を表示したまま、行ごとに高さを調整して黒い隙間が出ないように敷き詰めます(縦方向のみ数%程度の比率調整が入ることがあります)。
- ウインドウのリサイズや動画の入れ替わりに合わせてレイアウトが自動で追従します。

## 補足

- ロード中のタイルは黒く表示されます(通常は数百ミリ秒程度)。
- マルチビューの各動画は引き続き無音で再生されます。MP3 フォルダの音声再生は従来どおり独立して続きます。
