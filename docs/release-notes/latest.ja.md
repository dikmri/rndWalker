# rndWalker v0.2.3

マルチビューの操作性改善と自動アップデートの修正リリースです。

## 改善内容

### マウスホイールで動画サイズを変更

- マルチビュー中にマウスホイールを上下すると、動画サイズ(タイルの目安サイズ)を変更できるようになりました。上で拡大、下で縮小です。
- レイアウトは即座に追従し、再生中の動画はそのまま維持されます。設定値は自動保存されます。

### 自動アップデートが一発で最新版に上がるように

- 2 バージョン以上離れた古いアプリから自動アップデートすると、1 バージョンずつしか上がらず再起動を繰り返す必要があった問題を修正しました。
- 最新リリースを直接取得して一度で最新版に更新されます。

## 補足

- この修正自体は v0.2.3 以降のアプリに含まれるため、v0.2.2 以前からのアップデートでは従来どおり段階的に上がる場合があります。
