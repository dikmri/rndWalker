# rndWalker v0.1.16

動画を画面いっぱいに敷き詰めて再生できるマルチビュー機能を追加したリリースです。

## 新機能

- 設定画面に `マルチビューを有効にする` チェックボックスを追加しました。
- 設定画面に `動画サイズ` スライダーを追加しました。
- マルチビュー有効時、動画フォルダ内の動画を画面全体に敷き詰めて同時再生できるようにしました。
- 動画のアスペクト比を維持したままタイル表示します。
- 同じ画面内では可能な限り別々の動画を選び、動画数が足りない場合のみ重複を許可します。
- マルチビュー中の `D` キーで表示動画を再シャッフルできます。

## 補足

- マルチビューの各動画は無音で再生されます。MP3 フォルダの音声再生は従来どおり独立して続きます。
