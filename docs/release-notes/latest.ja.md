# rndWalker v0.1.12

Windows 版と UI 表示まわりの修正リリースです。

## 修正内容

- 日本語表示用フォントをアプリに同梱し、環境依存で日本語が四角表示になる問題を修正しました。
- Windows 版で起動時に CUI が表示されないようにしました。
- 再生画面左上のステータス表示を削除しました。
- 右上の設定ボタンを半透明の日本語ボタンへ変更し、マウスオーバー時だけ濃く表示されるようにしました。
- 動画終端前に次の動画をプリロードし、動画間の待ち時間を短縮しました。
- README とリリースノートを日本語正本に変更し、多言語ドキュメントを自動生成する workflow を追加しました。
