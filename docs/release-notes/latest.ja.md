# rndWalker v0.2.4

マルチビューの動画切り替えをシームレスにする改善リリースです。

## 改善内容

### 次の動画への切り替えがスムーズに

- 各タイルで動画が終わる数秒前に次の動画を裏で先行ロードし、終了の瞬間に即座に切り替わるようになりました。従来は終了後にロードを開始していたため、切り替わりまで前のフレームで一瞬止まって見えていました。
- 古い動画プレイヤーの停止・破棄を専用のバックグラウンドスレッドに移しました。従来は切り替えの瞬間に画面全体がわずかに固まることがありました(複数のタイルが続けて切り替わるとカクつきとして見えていた現象です)。再シャッフルや通常再生のスキップ時のカクつきも同時に解消されています。

## 補足

- 先行ロードが間に合わなかった場合のみ、従来どおり前のフレームを表示したまま短時間待機します。
- マルチビューの各動画は引き続き無音で再生されます。MP3 フォルダの音声再生は従来どおり独立して続きます。
