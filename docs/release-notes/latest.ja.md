# rndWalker v0.2.7

Windows でタスクバーにアプリアイコンが表示されない不具合を修正したリリースです。

## 修正内容

### タスクバーとタスク切替のアイコン

- Windows のタスクバー、`Alt` + `Tab` のタスク切替、タイトルバーに rndWalker のアイコンが表示されるようになりました。
- これまでは実行ファイルにアイコンが埋め込まれていてもウィンドウ側の大アイコンが未設定のままで、エクスプローラーでは正しく表示される一方、タスクバーだけが既定のアイコンになっていました。

## その他

- 起動時とウィンドウアイコン適用時の診断ログを、実行ファイルと同じ場所の `logs/rndwalker.log` に出力するようになりました。
