# rndWalker v0.2.2

v0.2.1 のマルチビューに関する不具合修正リリースです。

## 修正内容

### 次の動画への切り替えが固まる問題を修正

- 最初のフレームをデコードできない動画ファイルがあると、読み込み処理が永久に固まり以降の読み込みがすべて止まってしまう問題を修正しました。
- 特定のウインドウサイズでタイル数の調整が振動し、無駄な読み込みが大量発生して本来の動画切り替えが遅れる問題を修正しました。
- バックグラウンドの読み込みワーカーを 2 本から 3 本に増やし、切り替えをより軽快にしました。

### フルスクリーンで下半分の表示が崩れる問題を修正

- 画面に合わせた縦方向の補正計算を廃止しました。動画は一切変形されず、行ごとに高さを揃えて上から敷き詰め、最下段は画面の下に少し見切れる方式になりました。
- これによりフルスクリーンでも動画が正しく敷き詰められます。

## 補足

- ロード中のタイルは黒く表示されます(通常は数百ミリ秒程度)。
- マルチビューの各動画は引き続き無音で再生されます。MP3 フォルダの音声再生は従来どおり独立して続きます。
