# rndWalker v0.2.0

パフォーマンスの大幅改善とコード整理のリリースです。ユーザー操作・キー割り当て・設定項目に変更はありません。

## 改善内容

### マルチビューの軽量化

- 各タイルをセルの表示サイズに合わせた解像度で縮小デコードするようになりました。従来はネイティブ解像度でデコード・GPU 転送していたため、多タイル時の負荷が高くなっていました。
- スケーラをフレームごとに再生成せずキャッシュするようにしました。
- 各タイルはデコードスレッド 1 本・ループフィルタ省略・非参照フレームスキップの省力デコードで動作します。
- 使用しない音声・字幕タイマースレッドを生成しないようにしました。

### UI フリーズの解消

- Player の生成（最初のフレームのデコード）をバックグラウンドワーカーに移譲しました。マルチビューの再シャッフル（D キー）や動画スキップ時に画面が固まらなくなりました。
- スキップ時は次の動画の準備ができるまで現在の動画が再生され続けます。

### マルチビューのリサイズ改善

- ウインドウサイズ変更時に全タイルを作り直さず、増えた分だけ追加・減った分だけ削除するようにしました。再生中のタイルはそのまま維持されます。
- タイル終了時は前のフレームを表示したまま裏で次の動画をロードし、完了後に差し替えます。

### 単一再生の軽量化

- 通常の単一再生もウインドウ解像度に合わせた縮小デコードに対応しました。4K 動画を小さいウインドウで再生する場合などに負荷が軽減されます。

### コード整理

- `src/app.rs`（1346 行）を `app.rs` / `playback.rs` / `multiview.rs` / `ui.rs` / `loader.rs` に分割し、保守性を向上させました。
- `egui-video` を `vendor/egui-video` にフォークし、上記の最適化を反映しました。

## 補足

- ロード中のタイルは黒く表示されます（通常は数百ミリ秒程度）。
- マルチビューの各動画は引き続き無音で再生されます。MP3 フォルダの音声再生は従来どおり独立して続きます。
