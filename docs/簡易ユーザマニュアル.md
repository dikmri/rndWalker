# Random Video Player - 簡易ユーザマニュアル

## 事前準備

### Node.js のインストール

1. https://nodejs.org/ にアクセス
2. 「LTS」版をダウンロード（推奨）
3. ダウンロードしたインストーラーを実行
4. すべてデフォルト設定のまま「Next」を押してインストール完了

### インストール確認

コマンドプロンプトまたはPowerShellを開いて以下を実行：

```
node --version
npm --version
```

バージョン番号が表示されればOK。

---

## 開発環境での動作確認

### 1. 依存パッケージのインストール

プロジェクトフォルダで以下を実行（初回のみ）：

```
npm install
```

### 2. アプリの起動

```
npm start
```

アプリが起動します。

### 3. 初回設定

1. 起動すると設定画面が表示されます
2. 「Browse」ボタンでMP4フォルダを選択
3. 「Browse」ボタンでMP3フォルダを選択
4. 「Save」ボタンで保存

動画と音声がランダムに再生されます。

---

## キーボード操作

| キー | 機能 |
|------|------|
| F11 | フルスクリーン切替 |
| M | ミュート切替 |
| ↑ | 音量アップ |
| ↓ | 音量ダウン |
| → | 次のランダム動画へ |
| ← | 前の動画に戻る |
| Esc | フルスクリーン解除 |

---

## exeファイルの作成（ビルド）

### 1. ビルドコマンドの実行

```
npm run build
```

### 2. 出力先

ビルドが完了すると `dist` フォルダに以下が作成されます：

- `Random Video Player Setup x.x.x.exe` - インストーラー
- `win-unpacked/` - インストール不要の実行ファイル

### 3. 配布

- インストーラーを配布する場合: `Random Video Player Setup x.x.x.exe` を渡す
- インストール不要で使う場合: `win-unpacked` フォルダごと渡す

---

## トラブルシューティング

### 「npm」が認識されない

→ Node.js を再インストールしてください

### 動画が再生されない

→ MP4フォルダに `.mp4` ファイルがあるか確認してください

### 音声が再生されない

→ MP3フォルダに `.mp3` ファイルがあるか確認してください

### 設定をリセットしたい

→ アプリを閉じて、以下のフォルダを削除：
```
%APPDATA%/elc-ranvids/
```
