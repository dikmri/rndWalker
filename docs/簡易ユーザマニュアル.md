# rndWalker 簡易ユーザマニュアル

## 初回設定

1. `rndWalker` を起動します。
2. 設定画面で `MP4 Folder 1` と `MP3 Folder` を選択します。
3. 必要に応じて `MP4 Folder 2`、`MP4 Folder 3`、各グループのサブフォルダを追加します。
4. `Save` を押すと、動画と音声のランダム再生が始まります。

設定はOS標準の設定ディレクトリに `settings.json` として保存されます。

## プリセット

- `Save as Preset`: 現在のフォルダ入力を名前付きで保存します。
- `Load`: 選択したプリセットを入力欄に反映します。反映後に `Save` で適用します。
- `Delete`: 選択したプリセットを削除します。

## マルチビュー

設定画面で `マルチビューを有効にする` にチェックを入れて `Save` を押すと、現在の動画フォルダ内の動画が画面全体に敷き詰められて同時再生されます。

`動画サイズ` スライダーはタイルサイズの目安です。各動画はカットも変形もされずに全体が表示され、行ごとに高さを揃えて黒い隙間が出ないように敷き詰められます。最下段の行は画面の下に少し見切れることがあります。同じ画面内では可能な限り別々の動画が選ばれます。動画数が少ない場合は重複して表示されます。

マルチビュー中の動画は無音で再生されます。MP3 フォルダの音声は通常再生時と同じようにランダム再生されます。

各タイルはセルの表示サイズに合わせた解像度で縮小デコードされます。多タイル時やリサイズ時も動作が軽快です。動画の切り替えはバックグラウンドで準備され、ロード中は黒いセルが短時間表示されます。`D` キーによる再シャッフルやフォルダ切り替えでも画面がフリーズしません。

## キーボード操作

| キー | 機能 |
|------|------|
| F5 | 動画フォルダを再読み込み |
| F11 | フルスクリーン切替 |
| Esc | フルスクリーン解除、または設定画面を閉じる |
| M | ミュート切替 |
| W | 音量アップ |
| S | 音量ダウン |
| D | 次のランダム動画へ。マルチビュー中は再シャッフル |
| A | 前の動画に戻る。マルチビュー中は無効 |
| ← | フォルダ1の動画のみ再生 |
| ↑ | フォルダ2の動画のみ再生 |
| → | フォルダ3の動画のみ再生 |
| ↓ | 全フォルダの動画を再生 |

通常再生では、フォルダ切り替えは現在再生中の動画が終わってから反映されます。マルチビュー中はすぐに切り替わります。

## 自動更新

リリース版は起動時にGitHub Releasesを確認します。新しいバージョンがある場合はダウンロードと実行ファイルの置き換えを行い、完了後に再起動を促します。

デバッグビルドでは誤更新を避けるため、自動更新はスキップされます。

## 開発者向けビルド

RustとFFmpeg 7の開発用ライブラリが必要です。

```powershell
cargo build --release
```

旧Electron版は `legacy/electron/` に退避されています。今後の開発はRust版を基準にしてください。
