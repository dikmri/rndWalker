# Random Video Player - 簡易ユーザマニュアル

## 事前準備

### Node.js のインストール

1. https://nodejs.org/ にアクセス
2. 「LTS」版をダウンロード（推奨）
3. ダウンロードしたインストーラーを実行
4. すべてデフォルト設定のまま「Next」を押してインストール完了

### インストール確認

コマンドプロンプトまたはPowerShellを開いて以下を実行：

```
node --version
npm --version
```

バージョン番号が表示されればOK。

---

## 開発環境での動作確認

### 1. 依存パッケージのインストール

プロジェクトフォルダで以下を実行（初回のみ）：

```
npm install
```

### 2. アプリの起動

```
npm start
```

アプリが起動します。

### 3. 初回設定

1. 起動すると設定画面が表示されます
2. 「Browse」ボタンでMP4フォルダ1を選択（必須）
3. MP4フォルダ2・3は任意で設定可能（「Browse」で選択、「Clear」でクリア）
4. 「Browse」ボタンでMP3フォルダを選択
5. 「Save」ボタンで保存

動画と音声がランダムに再生されます。

---

## キーボード操作

| キー | 機能 |
|------|------|
| F5 | 動画フォルダを再読み込み |
| F11 | フルスクリーン切替 |
| M | ミュート切替 |
| W | 音量アップ |
| S | 音量ダウン |
| D | 次のランダム動画へ |
| A | 前の動画に戻る |
| ← | フォルダ1の動画のみ再生 |
| ↑ | フォルダ2の動画のみ再生 |
| → | フォルダ3の動画のみ再生 |
| ↓ | 全フォルダの動画を再生 |
| Esc | フルスクリーン解除 |

※ フォルダ切り替えは現在再生中の動画が終わってから反映されます。
※ フォルダが1つしか設定されていない場合、矢印キーでの切り替えは無効です。

## インストーラーでのインストール

### 新規インストール

1. `Random Video Player Setup x.x.x.exe` を実行
2. インストール先フォルダを選択（デフォルトのままでもOK）
3. 「Install」ボタンをクリック
4. インストール完了後、デスクトップとスタートメニューにショートカットが作成されます

### アップデート（既にインストール済みの場合）

1. 新しいバージョンの `Random Video Player Setup x.x.x.exe` を実行
2. そのまま同じフォルダにインストールすると既存のアプリが上書き更新されます
3. 設定（フォルダパスや音量）は保持されます

---

## exeファイルの作成（ビルド）- 開発者向け

### 1. ビルドコマンドの実行

```
npm run build
```

### 2. 出力先

ビルドが完了すると `dist` フォルダに以下が作成されます：

- `Random Video Player Setup x.x.x.exe` - インストーラー
- `win-unpacked/` - インストール不要の実行ファイル

### 3. 配布

- インストーラーを配布する場合: `Random Video Player Setup x.x.x.exe` を渡す
- インストール不要で使う場合: `win-unpacked` フォルダごと渡す

## トラブルシューティング

### 「npm」が認識されない

→ Node.js を再インストールしてください

### 動画が再生されない

→ MP4フォルダに `.mp4` ファイルがあるか確認してください

### 音声が再生されない

→ MP3フォルダに `.mp3` ファイルがあるか確認してください

### 設定をリセットしたい

→ アプリを閉じて、以下のフォルダを削除：
```
%APPDATA%/elc-ranvids/
```
