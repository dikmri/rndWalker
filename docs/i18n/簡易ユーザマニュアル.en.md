# rndWalker Simple User Manual

## Initial setup

1. Start `rndWalker`.
2. Select `MP4 Folder 1` and `MP3 Folder` on the settings screen.
3. Add `MP4 Folder 2`, `MP4 Folder 3`, and subfolders for each group as necessary.
4. Press `Save` and the video and audio will start playing randomly.

Settings are saved as `settings.json` in the OS standard settings directory.

## preset

- `Save as Preset`: Saves the current folder input with a name.
- `Load`: Reflects the selected preset in the input field. Apply with `Save` after reflecting.
- `Delete`: Delete the selected preset.

## multi view

If you check `Enable multi-view` on the settings screen and press `Save`, the videos in the current video folder will be spread across the entire screen and played simultaneously.

The `Video Size` slider is a guide to the tile size. Each video is displayed in its entirety without being cut, and the height is adjusted line by line to ensure there are no black gaps. If possible, different videos will be selected within the same screen. If the number of videos is small, duplicates will be displayed.

Videos in multi-view will be played without sound. The audio in the MP3 folder will be played randomly in the same way as normal playback.

Each tile is reduced and decoded at a resolution that matches the display size of the cell. It operates easily even when using multiple tiles or resizing. The video transition will be prepared in the background and a black cell will briefly appear while it loads. The screen does not freeze even when reshuffling or switching folders using the `D` key.

## keyboard operation

| key | function |
|------|------|
| F5 | Reload video folder |
| F11 | Full screen switching |
| Esc | Cancel full screen or close settings screen |
| M | Mute switch |
| W | volume up |
| S | volume down |
| D | Go to the next random video. Reshuffle during multiview |
| A | Return to previous video. Disabled during multiview |
| ← | Play only videos in folder 1 |
| ↑ | Play only videos in folder 2 |
| → | Play only videos in folder 3 |
| ↓ | Play videos in all folders |

During normal playback, folder switching will take effect after the currently playing video ends. During multi-view, it will switch immediately.

## automatic update

For release versions, check GitHub Releases at startup. If a new version is available, it will download and replace the executable file, and prompt you to restart after completion.

Automatic updates are skipped in debug builds to avoid accidental updates.

## Build for developers

Requires Rust and FFmpeg 7 development libraries.

```powershell
cargo build --release
```

The old Electron version is saved in `legacy/electron/`. Please use the Rust version as the standard for future development.
