# rndWalker 简单用户手册

## 初始设置

1. 启动`rndWalker`。
2. 在设置屏幕上选择“MP4 文件夹 1”和“MP3 文件夹”。
3. 根据需要为每个组添加“MP4 文件夹 2”、“MP4 文件夹 3”和子文件夹（您可以使用“+添加文件夹”添加任意数量的文件夹。如果文件夹数量增加，设置窗口将滚动）。如果启用数字键盘操作，还将显示“MP4 文件夹 4”至“MP4 文件夹 9”。
4. 按“保存”，视频和音频将开始随机播放。

设置在操作系统标准设置目录中保存为“settings.json”。

## 预设

- `另存为预设`：保存当前输入的文件夹名称。
- `Load`：将选定的预设应用到输入字段。反映后使用“保存”应用。
- 如果在选择预设的情况下按“保存”，当前设置和该预设将被覆盖并同时保存。
- `删除`：删除选定的预设。
- 如果您将 F1-F4、F6-F10 或 F12 指定为“快捷方式”，则只需在设置屏幕关闭的情况下按该键即可立即应用预设。如果分配相同的键，则最后设置的预设优先。

## 多视图

如果您在设置屏幕上选中“启用多视图”并按“保存”，当前视频文件夹中的视频将遍布整个屏幕并同时播放。

“视频大小”滑块是图块大小的指南。每个视频都是完整显示的，没有被剪切或转换，并且每一行都被布置到相同的高度，以便没有黑色间隙。屏幕底部的底行可能会被稍微切断。如果可能，将在同一屏幕内选择不同的视频。如果视频数量较少，则会显示重复的视频。

多视图视频将无声播放。 MP3 文件夹中的音频将以与正常播放相同的方式随机播放。

每个图块都会按比例缩小并解码为与单元格的显示尺寸相匹配的分辨率。即使使用多个图块或调整大小时，操作也很轻松。下一个视频在播放结束前几秒钟在幕后准备，并在播放结束时切换到下一个视频。即使使用“D”键重新排列或切换文件夹时，屏幕也不会冻结。

## 键盘/鼠标操作

| 钥匙 | 功能 |
|------|------|
| F5 | 重新加载视频文件夹 |
| F11 | 全屏切换 |
| Esc键 | 取消全屏或关闭设置屏幕 |
| 中号 | 静音开关 |
| 瓦 | 调高音量 |
| S | 音量调低 |
| D | 转到下一个随机视频。多视图期间重新洗牌 |
| 一个 | 返回上一个视频。多视图期间禁用 |
| ← | 仅播放文件夹 1 中的视频 |
| ↑ | 仅播放文件夹 2 中的视频 |
| → | 仅播放文件夹 3 中的视频 |
| ↓ | 播放所有文件夹中的视频 |
| 设置F1~F4/F6~F10/F12 | 即时切换预设 |
| 数字键盘1~9/0 | 仅在设置时切换至各文件夹1至9/所有文件夹 |
| 鼠标滚轮 | 在多视图期间更改视频尺寸（向上放大/向下缩小） |

正常播放时，文件夹切换会在当前播放视频结束后生效。多视图时，会立即切换。

通过在设置屏幕上打开“启用使用数字键盘的文件夹切换和 9 组”，可以使用使用数字键盘进行的文件夹切换和文件夹 4 至 9。即使关闭，文件夹 4 至 9 的输入内容也会保留。

## 自动更新

对于发布版本，请在启动时检查 GitHub Releases。如果有新版本，会下载并替换可执行文件，完成后提示重新启动。

在调试版本中会跳过自动更新，以避免意外更新。

## 为开发者构建

需要 Rust 和 FFmpeg 7 开发库。

```powershell
cargo build --release
```

旧的 Electron 版本保存在 `legacy/electron/` 中。请使用Rust版本作为未来开发的标准。
