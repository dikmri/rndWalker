# rndWalker 简单用户手册

## 初始设置

1. 启动`rndWalker`。
2. 在设置屏幕上选择“MP4 文件夹 1”和“MP3 文件夹”。
3. 根据需要为每个组添加“MP4 文件夹 2”、“MP4 文件夹 3”和子文件夹。
4. 按“保存”，视频和音频将开始随机播放。

设置在操作系统标准设置目录中保存为“settings.json”。

## 预设

- `另存为预设`：保存当前输入的文件夹名称。
- `Load`：反映输入字段中选定的预设。反映后使用“保存”应用。
- `删除`：删除选定的预设。

## 多视图

如果您在设置屏幕上选中“启用多视图”并按“保存”，当前视频文件夹中的视频将遍布整个屏幕并同时播放。

“视频大小”滑块是图块大小的指南。视频比例保持不变，并且从每个图块的中心裁剪视频以避免黑边。如果可能，将在同一屏幕内选择不同的视频。如果视频数量较少，则会显示重复的视频。

多视图视频将无声播放。 MP3 文件夹中的音频将以与正常播放相同的方式随机播放。

## 键盘操作

| 钥匙 | 功能 |
|------|------|
| F5 | 重新加载视频文件夹 |
| F11 | 全屏切换 |
| Esc键 | 取消全屏或关闭设置屏幕 |
| 中号 | 静音开关 |
| 瓦 | 调高音量 |
| S | 音量调低 |
| D | 转到下一个随机视频。多视图期间重新洗牌 |
| 一个 | 返回上一个视频。多视图期间禁用 |
| ← | 仅播放文件夹 1 中的视频 |
| ↑ | 仅播放文件夹 2 中的视频 |
| → | 仅播放文件夹 3 中的视频 |
| ↓ | 播放所有文件夹中的视频 |

正常播放时，文件夹切换会在当前播放视频结束后生效。多视图时，会立即切换。

## 自动更新

对于发布版本，请在启动时检查 GitHub Releases。如果有新版本，会下载并替换可执行文件，完成后提示重新启动。

在调试版本中会跳过自动更新，以避免意外更新。

## 为开发者构建

需要 Rust 和 FFmpeg 7 开发库。

```powershell
cargo build --release
```

旧的 Electron 版本保存在 `legacy/electron/` 中。请使用Rust版本作为未来开发的标准。
