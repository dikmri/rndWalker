# rndWalker 간단한 사용자 매뉴얼

## 초기 설정

1. `rndWalker`를 시작합니다.
2. 설정 화면에서 `MP4 Folder 1`과 `MP3 Folder`를 선택하십시오.
3. 필요에 따라 `MP4 Folder 2`, `MP4 Folder 3`, 각 그룹의 하위 폴더를 추가합니다.
4. `Save`를 누르면 동영상과 오디오의 무작위 재생이 시작됩니다.

설정은 OS 표준 설정 디렉토리에 `settings.json`으로 저장됩니다.

## 프리셋

- `Save as Preset`: 현재 폴더 입력을 이름으로 저장합니다.
- `Load`: 선택한 프리셋을 입력란에 반영합니다. 반영 후에 `Save`로 적용합니다.
- `Delete`: 선택한 프리셋을 삭제합니다.

## 키보드 조작

| 키 | 기능 |
|------|------|
| F5 | 동영상 폴더 다시 로드 |
| F11 | 전체 화면 전환 |
| Esc | 전체 화면 해제 또는 설정 화면 닫기 |
| M | 음소거 전환 |
| W | 볼륨 업 |
| S | 볼륨 다운 |
| D | 다음 무작위 동영상으로 |
| A | 이전 동영상으로 돌아가기 |
| ← | 폴더 1 동영상만 재생 |
| ↑ | 폴더 2 동영상만 재생 |
| → | 폴더 3 동영상만 재생 |
| ↓ | 모든 폴더의 동영상 재생 |

폴더 전환은 현재 재생 중인 동영상이 끝난 후 반영됩니다.

## 자동 업데이트

릴리스 버전은 시작 시 GitHub Releases를 확인합니다. 새 버전이 있는 경우 다운로드 및 실행 파일을 대체하고 완료 후 다시 시작하라는 메시지를 표시합니다.

디버그 빌드는 잘못된 업데이트를 피하기 위해 자동 업데이트를 건너뜁니다.

## 개발자용 빌드

Rust와 FFmpeg 7 개발 라이브러리가 필요합니다.

```powershell
cargo build --release
```

구 Electron판은 `legacy/electron/` 에 퇴피되고 있습니다. 향후 개발은 Rust 버전을 기준으로 하십시오.
