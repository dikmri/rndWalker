# rndWalker 간단한 사용자 매뉴얼

## 초기 설정

1. `rndWalker`를 시작합니다.
2. 설정 화면에서 `MP4 Folder 1`과 `MP3 Folder`를 선택하십시오.
3. 필요에 따라 `MP4 Folder 2`, `MP4 Folder 3`, 각 그룹의 하위 폴더를 추가합니다.
4. `Save`를 누르면 동영상과 오디오의 무작위 재생이 시작됩니다.

설정은 OS 표준 설정 디렉토리에 `settings.json`으로 저장됩니다.

## 프리셋

- `Save as Preset`: 현재 폴더 입력을 이름으로 저장합니다.
- `Load`: 선택한 프리셋을 입력란에 반영합니다. 반영 후에 `Save`로 적용합니다.
- `Delete`: 선택한 프리셋을 삭제합니다.

## 멀티뷰

설정 화면에서 `멀티 뷰 활성화`를 체크하고 `Save`를 누르면 현재 동영상 폴더의 동영상이 화면 전체에 깔려 동시 재생됩니다.

`동영상 사이즈` 슬라이더는 타일 사이즈의 기준입니다. 각 동영상은 자르지 않고 전체가 표시되며 행마다 높이를 조정하여 검은 틈이 나지 않도록 깔려 있습니다. 같은 화면에서 가능한 한 별도의 동영상을 선택합니다. 동영상 수가 적으면 중복으로 표시됩니다.

멀티뷰 동영상은 무음으로 재생됩니다. MP3 폴더의 오디오는 일반 재생과 마찬가지로 무작위로 재생됩니다.

각 타일은 셀의 표시 크기에 맞는 해상도로 축소 디코딩됩니다. 다 타일시나 리사이즈시도 동작이 경쾌합니다. 동영상 전환은 백그라운드에서 준비되며 로드하는 동안 검은 셀이 잠시 표시됩니다. `D` 키에 의한 재 셔플이나 폴더 전환으로도 화면이 정지되지 않습니다.

## 키보드 조작

| 키 | 기능 |
|------|------|
| F5 | 동영상 폴더 다시 로드 |
| F11 | 전체 화면 전환 |
| Esc | 전체 화면 해제 또는 설정 화면 닫기 |
| M | 음소거 전환 |
| W | 볼륨 업 |
| S | 볼륨 다운 |
| D | 다음 무작위 동영상으로. 멀티뷰 중에는 다시 셔플 |
| A | 이전 동영상으로 돌아갑니다. 멀티 뷰 중에 비활성화 |
| ← | 폴더 1 동영상만 재생 |
| ↑ | 폴더 2 동영상만 재생 |
| → | 폴더 3 동영상만 재생 |
| ↓ | 모든 폴더의 동영상 재생 |

일반 재생에서는 폴더 전환이 현재 재생 중인 동영상이 끝난 후 반영됩니다. 멀티 뷰 중에는 즉시 전환됩니다.

## 자동 업데이트

릴리스 버전은 시작 시 GitHub Releases를 확인합니다. 새 버전이 있는 경우 다운로드 및 실행 파일을 대체하고 완료 후 다시 시작하라는 메시지를 표시합니다.

디버그 빌드는 잘못된 업데이트를 피하기 위해 자동 업데이트를 건너뜁니다.

## 개발자용 빌드

Rust와 FFmpeg 7 개발 라이브러리가 필요합니다.

```powershell
cargo build --release
```

구 Electron판은 `legacy/electron/` 에 퇴피되고 있습니다. 향후 개발은 Rust 버전을 기준으로 하십시오.
