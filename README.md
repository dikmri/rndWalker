# ランダム動画・音声プレイヤー 設計書

## 概要

- **プロジェクト名**: elc_ranVids
- **作成日**: 2026-01-11
- **技術スタック**: Electron + HTML + CSS + JavaScript
- **対象OS**: Windows（将来的にMac/Linux対応予定）

## 機能要件

### 1. メディア再生機能

- 指定フォルダ内のMP4ファイルをランダムに再生
- 指定フォルダ内のMP3ファイルを同時にランダムに再生
- 動画と音声は独立して再生される

### 2. フォルダ設定機能

- 初回起動時にMP4フォルダとMP3フォルダを選択するダイアログを表示
- 設定はローカルストレージ（electron-store）に保存
- 次回起動時は自動で保存されたフォルダを読み込む
- 設定画面から変更可能

### 3. キーボードショートカット

| キー | 機能 |
|------|------|
| F11 | フルスクリーンモード切替 |
| M | ミュート切替 |
| ↑ | 音量アップ |
| ↓ | 音量ダウン |
| → | 次のランダム動画にスキップ |
| ← | 前に再生していた動画に戻る |

### 4. 再生履歴

- 再生した動画の履歴を保持
- ←キーで前の動画に戻れるように実装

## 技術詳細

### メインプロセス（main.js）

- ウィンドウ作成・管理
- IPC通信によるフォルダ選択ダイアログ
- フルスクリーン切替処理
- 設定の読み込み・保存
- カスタム`media://`プロトコルの登録（ローカルファイル再生用）

### プリロード（preload.js）

- contextBridgeによるAPIの公開
- セキュアなIPC通信の橋渡し

### レンダラープロセス（renderer.js）

- 動画・音声の再生制御
- キーボードイベントのハンドリング
- 再生履歴の管理
- UI更新

### 設定管理

- electron-storeを使用して設定を永続化
- 保存する設定項目：
  - mp4FolderPath: 動画フォルダのパス
  - mp3FolderPath: 音声フォルダのパス
  - volume: 音量設定

## UI設計

### メイン画面

- 動画プレイヤー（画面全体）
- オーバーレイで表示するコントロール（オプション）
- 設定ボタン（歯車アイコン）

### 設定画面（モーダル）

- MP4フォルダ選択
- MP3フォルダ選択
- 保存・キャンセルボタン

## 依存パッケージ

- electron: Electronフレームワーク
- electron-store: 設定の永続化
- electron-builder: exeファイルのビルド

## 変更履歴

### 2026-01-11

- 初期実装
- MP4再生不具合を修正: Windowsファイルパスを正しいfile:// URL形式に変換する`pathToFileURL`関数を追加
- MP4/MP3再生を修正: カスタム`media://`プロトコルを実装してローカルファイルを正しく配信
- MP3ループ問題を修正: `<audio>`タグから`loop`属性を削除し、再生終了時に次のランダムなファイルを再生するように変更
- メディア再生を修正: `protocol.registerSchemesAsPrivileged()`でカスタムプロトコルを特権スキームとして登録（stream対応）
- save-settingsエラーを修正: undefined値を保存しないようにチェックを追加
- 初期ボリュームを10%に変更
- 映像再生を修正: `webSecurity: false`を設定し、直接`file://`URLでメディアファイルにアクセス
- 映像再生を修正: IPC経由でファイルをbase64で読み込み、BlobURLで再生する方式に変更
- 音声再生を修正: `playRandomAudio`も同様にBlobURL方式に変更（pathToMediaURL関数の削除による不具合を修正）
- CSPを修正: `blob:`を明示的に許可
- 動画プリロードシステムを実装: 3つの動画を先読みしてシームレスな再生を実現
- 包括的なデバッグログを追加: タイムスタンプとカテゴリ付きのログ出力機能（INIT, VIDEO, AUDIO, PRELOAD, SETTINGS, VOLUME, UI, EVENT, FILE, KEYBOARD, UTIL）
